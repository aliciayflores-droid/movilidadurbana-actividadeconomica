# movilidadurbana-actividadeconomica
## ¿De qué trata este proyecto? 
*Dentro de éste proyecto de movilidad urbana y actividad económica, se analizaron dataset que incluian información de distintos países, con datos de su actividad económica PIB per cápita y datos de la móvilidad y tiempos de traslado para cada país.*
## ¿Qué contiene este repositorio? 
*Éste repositorio, contiene el análisis de los datos, la unión de ambos data sets, calculando los promedios de tráfico para cada ciudad, y la unión de éstos datos con la movilidad económica, así como un análisis y conclusiones de los datos obtenidos*
 **Éste notebook puede abrirse desde Jupyter Notebook o Google colab, se incluye el archivo completo, con gráficos y análisis paso a paso**
